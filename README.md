# Medical Quiz

Вебдодаток для тренування тестів з медичної хімії: **флешкартки** і **тест-самоперевірка**.
React + TypeScript + Vite + Tailwind CSS. Прогрес зберігається в `localStorage`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Production-збірка: `npm run build` (результат у `dist/`), перегляд: `npm run preview`.

## Дані та парсер

```
data/source/questions.txt   <- вихідний текст питань (редагуйте його)
scripts/parseQuestions.js   <- парсер
src/data/questions.json     <- згенерований JSON (його читає застосунок)
data/parser-errors.json     <- помилки та попередження парсера
```

Після змін у `questions.txt`:

```bash
npm run parse
```

Парсер виводить статистику (кількість питань, помилки, розбивка по темах) і **нічого не видаляє мовчки**.

### Формат вихідного файлу

```
ТЕМА 1. Назва теми
1.Текст питання (може займати кілька рядків)
*правильна відповідь
2.Питання з кількома правильними відповідями
*відповідь 1
*відповідь 2
```

* Нове питання: рядок `N.текст`. Правильна відповідь: рядок, що починається з `*`.
* Кілька рядків `*` = кілька правильних відповідей.
* У джерелі **немає хибних варіантів**, тому JSON містить `answers: string[]`, а `options` і `correctAnswer` = `null`.
* Питання без відповіді потрапляє в `parser-errors.json` (`reason`), а не в JSON.
* Попередження (`severity: "warning"`) — це місця для ручної перевірки: склеєні `відповідь + номер наступного питання` (розділяються автоматично) і порушення нумерації/дублі номерів у джерелі.

## Режими

* **Картки**: питання → клік/Enter/Пробіл → переворот → відповідь. ← → або свайп (на мобільному) для навігації. Позиція зберігається, на головній є «Продовжити навчання».
* **Тест**: випадкові 10 / 20 / 30 / усі питання, два типи (вибір на сторінці теми):
  * **З варіантами** — 1 правильна відповідь + 3 хибні. Клавіші 1–4 вибирають варіант. Після вибору відповідь заблокована, видно ✓/✗ і правильну відповідь.
  * **Самоперевірка** — ви пригадуєте відповідь, відкриваєте її й позначаєте «Знав / Не знав».
  * Підсумок, історія результатів, «Повторити тест», «Повторити помилки» (зберігають обраний тип).

### Звідки беруться хибні варіанти

У джерелі їх немає, тому вони **не вигадуються**: це реальні правильні відповіді інших питань тієї ж теми (`src/utils/quiz.ts → buildChoices`). Добір: та сама «форма» відповіді (число / формула / фраза), схожа довжина й тема питання. Відповіді повторних формулювань того самого питання виключаються, бо вони теж правильні. Іноді хибний варіант може бути близьким за змістом до правильного — це особливість даних, а не помилка парсера.

## Адаптивність

Телефон (від 320px), планшет і комп'ютер: теми в 1 / 2 / 3 колонки, на desktop сторінка теми двоколонкова, картка й текст питання збільшуються.

## localStorage

Ключ `medical-quiz:v1`. Зберігається: остання тема, результат останнього тесту та для кожної теми — `currentQuestion`, `completed` (переглянуті/оцінені питання, з них рахується прогрес %), `testHistory` (звідси best/last/average), `incorrectQuestions`. Скинути прогрес: очистити дані сайту в браузері.
